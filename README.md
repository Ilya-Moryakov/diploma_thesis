# 🎓 Дипломный проект: Автоматизированный фреймворк тестирования (API & UI)

Фреймворк предназначен для сквозного автоматизированного тестирования серверной и клиентской частей сервиса доставки еды. Проект построен на базе **Python**, **Pytest** и **Selenium WebDriver** с использованием паттерна **Page Object Model (POM)** и генерацией отчетов в **Allure**.

---

## 🛠️ Технологический стек
* **Язык программирования:** Python 3.14+
* **Тест-раннер:** Pytest 8.3.2
* **UI Автоматизация:** Selenium WebDriver (взаимодействие с Chromium)
* **API Автоматизация:** Requests
* **Репорты и графики:** Allure Pytest 2.13.5

---

## 📂 Структура репозитория
* `pages/main_page.py` — Объектная модель страниц (Page Object) с нативными локаторами элементов интерфейса и JavaScript-инъекциями скроллинга.
* `test/` — Папка со всеми тест-кейсами:
  * `test_api_*.py` — Изолированные серверные тесты бэкенда (Профиль, Поиск, Корзина).
  * `test_ui_*.py` — Сценарии нативного гостевого тестирования интерфейса.
* `test/conftest.py` — Конфигурация фикстур, инициализация веб-драйвера и CDP-эмуляция геопозиции.
* `config.py` — Глобальные параметры конфигурации, базовые URL и сессионные токены.
* `requirements.txt` — Список зависимостей для быстрого развёртывания.

## 🚀 Инструкция по запуску тестов

### 1. Подготовка окружения
Перед запуском убедитесь, что у вас установлен Python, Allure CLI и выполнены следующие команды в терминале:
```bash
# Активация виртуального окружения
.venv\Scripts\activate

# Установка всех необходимых зависимостей
pip install -r requirements.txt
```

### 2. Запуск абсолютно всех тестов (API + UI одновременно)
Финальный контрольный прогон всей системы из 10 тест-кейсов в стандартном режиме:
```bash
pytest
```

### 3. Запуск тестов в режиме реального времени (с выводом логов в консоль)
Для подробного отслеживания шагов выполнения (отладка нативных кликов, адреса доставки и ввода параметров):
```bash
pytest -s
```

### 4. Запуск изолированных модулей (API или UI отдельно)
```bash
# Запустить только серверные тесты бэкенда
pytest test/ -k "api"

# Запустить только браузерные тесты интерфейса
pytest test/ -k "ui"
```

### 5. Запуск конкретного тест-кейса (на примере добавления товара)
```bash
pytest test/test_ui_3_cart_add.py -s
```

### 6. Генерация красивых графических отчетов Allure
```bash
# Запуск тестов со сбором результатов для Allure
pytest --alluredir=allure-results

# Генерация локального веб-сервера и просмотр интерактивных графиков в браузере
allure serve allure-results
```
